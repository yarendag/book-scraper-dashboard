# 📚 Book Scraper Dashboard

A Flask-based web application that scrapes book data, processes it, and presents it in an interactive dashboard with visual analytics.

---

## 🚀 Live Demo

👉 https://book-scraper-dashboard.onrender.com

---

## 🧠 Overview

This project is a full-stack web scraping and data visualization dashboard that:

* Scrapes book data from a target website
* Cleans and structures raw data
* Performs basic data processing and analysis
* Visualizes insights in an interactive dashboard

---

## 🛠️ Tech Stack

* Python
* Flask
* BeautifulSoup (Web Scraping)
* Pandas (Data Processing)
* Plotly (Data Visualization)
* HTML / CSS (Frontend)
* Gunicorn (Production Server)
* Render (Deployment)

---

## 📊 Features

* Automated web scraping pipeline
* Clean dataset generation
* Interactive dashboard UI
* Data visualization (charts & graphs)
* Fully deployed live web application

---

## ⚙️ Local Setup

```bash
git clone https://github.com/YOUR-USERNAME/book-scraper-dashboard.git
cd book-scraper-dashboard
pip install -r requirements.txt
python app.py
```

Then open:

[http://127.0.0.1:5000](http://127.0.0.1:5000)

---

## 🌐 Deployment

Live application deployed on Render:

👉 https://book-scraper-dashboard.onrender.com

Production server uses:

```bash
gunicorn app:app
```
